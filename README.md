Weather Web App 🌤️
A sleek and user-friendly weather application to get real-time weather updates for any location worldwide. Built with modern web technologies for accurate and dynamic weather forecasts.

🌟 Features
Real-time Weather: Current temperature, min, max and more.
Search by Location: Search weather data for cities across the globe.
Forecasts: Get weather predictions for a week
Responsive Design: Optimized for desktop and mobile use.

🚀 Tech Stack
Frontend: HTML, CSS, JavaScript, React.js
API: [WeatherAPI]
